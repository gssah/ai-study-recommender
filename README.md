# AI Study Recommendation App

## Overview

This project is a machine-learning based study recommendation system.

The application uses information about a student's study habits and academic performance to predict the level of academic support they may need.

It then provides personalized study recommendations based on the student's inputs.

## Why I Built This

I created this project because I am interested in how artificial intelligence can be used to personalize education.

Students have different study habits, strengths, and challenges. Factors such as study time, sleep, attendance, and previous academic performance can influence how much support a student may need.

This project allowed me to explore how machine learning can identify patterns in data and use those patterns to make predictions.

## Inputs

The model uses:

- Daily study hours
- Sleep hours
- Attendance percentage
- Previous grade

## Output

The machine-learning model predicts one of three support levels:

- Low
- Medium
- High

The program then provides personalized recommendations.

These may include:

- increasing study time
- improving sleep
- improving attendance
- using active recall
- using spaced repetition
- practicing weaker topics
- taking breaks during longer study sessions

## Machine Learning Model

This project uses a Random Forest Classifier.

Random Forest works by combining predictions from multiple decision trees to produce a final classification.
